# TyM Dulce — Descargas oficiales

Este repositorio publica los instaladores y paquetes de versiones de TyM Dulce.

- Las versiones de Android se publican como releases con etiquetas `apk-<número>`.
- Las versiones de Windows se publican como releases con etiquetas `desktop-<número>`.

El código fuente de la aplicación se mantiene en el repositorio privado del proyecto.
